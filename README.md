# Peer Voting System

A web-based **Peer Voting System** designed to provide a simple and organized platform for conducting peer-to-peer voting. The project allows users to participate in voting activities, submit their choices, and manage or view voting results.

## Features

* User-friendly voting interface
* Peer-to-peer voting functionality
* Vote submission and management
* Voting results
* Database integration
* Form validation
* Organized backend and frontend structure

## Purpose

The main purpose of this project is to develop a practical voting system and understand how user interactions, voting logic, database operations, and result management can be implemented in a web application.
